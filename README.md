# Precision 3D Modeler for Manus

An importable Manus AI skill with Blender Python modeling, mesh quality assurance, multi-angle preview rendering, GLB/FBX exports, automated tests, and a GitHub Actions Blender smoke test.

See `SKILL.md` for usage and the `scripts/` folder for the executable pipeline.

## Install

In Manus, open Skills → Add → Import from GitHub and use this repository URL. Alternatively, download the `.zip`/`.skill` archives generated by the **Check skill and Blender sample** GitHub Actions workflow.

## Local usage

Requires Blender installed on PATH, Python 3.9+, and optional pytest for tests.

```bash
python scripts/run_pipeline.py --script examples/modern_chair.py --outdir output/chair --name modern-chair --profile game --max-triangles 60000 --formats glb fbx
python -m pytest -q tests/test_pipeline.py tests/test_packaging.py
```

Outputs `.blend`, GLB/FBX, QA report, PNG renders, and logs. Automated checks cannot guarantee perfect visual accuracy, printable geometry, or import into every target engine. Inspect the output and verify in the target app.
